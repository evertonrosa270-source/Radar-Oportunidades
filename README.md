# RADAR OPORTUNIDADES V4

Correção da aba Produtos e Serviços.

## Como iniciar
No terminal da pasta:

npm install
npm run dev

O backend deve mostrar:
API inteligente em http://localhost:3000

O Vite mostrará o endereço do site.

Se o botão ainda não adicionar produtos, a tela agora mostrará a mensagem exata do erro.
