# RADAR OPORTUNIDADES — Repaginação visual

Esta versão aplica uma atualização visual ao frontend mantendo os fluxos de autenticação, WhatsApp Business, produtos, oportunidades, assinaturas, administração de clientes e estatísticas.

## O que mudou
- Interface clara e mais consistente, com hierarquia tipográfica, espaçamento e contraste revisados.
- Navegação lateral com estados ativos mais claros e responsividade para telas menores.
- Cartões, formulários, tabelas, botões, avisos e painéis com bordas e sombras mais sutis.
- Painel de visitantes e painel administrativo alinhados ao mesmo sistema visual.
- Emojis de status nas categorias de oportunidades substituídos por indicadores visuais discretos; ícones de ação padronizados.
- Melhorias de foco de teclado e respeito à preferência de movimento reduzido.

## Publicação
Envie os arquivos do ZIP ao repositório existente, preservando as variáveis de ambiente configuradas diretamente na Vercel e no Render. Não publique segredos ou arquivos `.env`.

## Validação deste pacote
A estrutura do ZIP e a sintaxe do servidor foram verificadas. O build completo do frontend não foi executado neste ambiente porque a instalação de dependências não terminou; execute `npm ci` e `npm run build` no pipeline do deploy para confirmar a compilação antes de publicar em produção.
