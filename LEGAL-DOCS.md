# Documentos legais do RADAR Oportunidades

As páginas públicas são:
- `/politica-de-privacidade/`
- `/termos-de-servico/`

Nesta versão, o servidor possui rotas explícitas para as duas páginas e para `/legal.css`, servindo os arquivos diretamente de `public/`. Isso evita que o catch-all do React ocupe essas URLs.

O texto foi estruturado considerando o funcionamento atual do RADAR, LGPD e requisitos de transparência do Google para apps que usam Login com Google. Antes de operação comercial definitiva, o responsável deve substituir/confirmar a identificação jurídica do controlador, endereço, canal formal de atendimento e demais dados empresariais reais.

As páginas não constituem aconselhamento jurídico. Recomenda-se revisão profissional antes da publicação comercial definitiva.
